# Сайт-портфолио Гиоргия Мачарашвили

**Сайт:** https://goravfx.github.io

AI-режиссёр · Generative Filmmaker · VFX Artist.

Сайт статический: GitHub Pages показывает файлы из этого репозитория как есть, без сборки и без серверов.
Любое изменение в ветке `main` появляется на сайте примерно через минуту.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная страница |
| `about/index.html` | Страница «Обо мне» с полной историей |
| `404.html` | Страница «Этот кадр не вошёл в монтаж» для несуществующих адресов |
| `assets/css/site.css` | Оформление. Цвета, шрифты и отступы заданы переменными в начале файла |
| `assets/js/site.js` | Мобильное меню, таймкод REC и фоновое видео на первом экране |
| `assets/img/` | Картинки сайта |
| `assets/fonts/` | Шрифты Unbounded, Onest и IBM Plex Mono (локальные копии Google Fonts) |
| `assets/og-cover.jpg` | Картинка-превью для Telegram, VK, WhatsApp и соцсетей |
| `assets/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Иконка сайта |

## Как поправить текст прямо на GitHub

1. Откройте нужный файл, например `index.html`.
2. Нажмите на значок карандаша (**Edit this file**) справа над содержимым.
3. Найдите нужный текст через Ctrl+F и исправьте его.
4. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
5. Через минуту-две обновите сайт.

## Как заменить картинку

1. Откройте папку `assets/img`.
2. Нажмите **Add file → Upload files** и загрузите новую картинку **с тем же именем**, например `jorun.webp`.
3. Нажмите **Commit changes**.

Широкие кадры лучше загружать шириной от 2000 px, портреты — от 1200 px. Формат — `.webp` или `.jpg`.

## Фоновое видео

Видео на первом экране — Vimeo-плеер в режиме фона. Адрес задан в `index.html`, в атрибуте `data-vimeo`.
Пока видео грузится или если Vimeo недоступен, показывается постер `assets/img/hero-poster.webp`.
Масштаб видео (чтобы спрятать чёрные полосы и титры рила) — переменная `--reel-zoom` в `assets/css/site.css`.
