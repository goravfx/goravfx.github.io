# Сайт-портфолио Гиоргия Мачарашвили

**Сайт:** https://goravfx.github.io · английская версия: https://goravfx.github.io/en/

AI-режиссёр · Generative Filmmaker · VFX Artist.

Сайт статический: GitHub Pages показывает файлы из этого репозитория как есть, без сборки и без серверов.
Любое изменение в ветке `main` появляется на сайте примерно через минуту.

Все ролики лежат прямо на сайте, без Vimeo и YouTube, поэтому открываются в любой стране и без VPN.

У сайта две языковые версии: русская (`/`) и английская (`/en/`). Переключатель с флагами — в шапке рядом с меню.
Если браузер посетителя не на русском, внизу появляется подсказка «This site is also available in English».
Для LinkedIn и иностранных заказчиков давайте ссылку https://goravfx.github.io/en/.

## Как поправить текст прямо на GitHub

1. Откройте нужный файл, например `index.html` (или `en/index.html` для английской версии).
2. Нажмите на значок карандаша (**Edit this file**) справа над содержимым.
3. Найдите нужный текст через Ctrl+F и исправьте его.
4. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
5. Через минуту-две обновите сайт.

## Как заменить картинку или ролик

1. Откройте папку `assets/img` или `assets/video`.
2. Нажмите **Add file → Upload files** и загрузите новый файл **с тем же именем**, например `jorun-preview.mp4`.
3. Нажмите **Commit changes**.

GitHub не принимает файлы больше 100 МБ, а файлы больше 50 МБ лучше не загружать. Ролик стоит заранее сжать в mp4 (H.264, звук AAC):
горизонтальные — 1280×720, вертикальные — 720×1280.
